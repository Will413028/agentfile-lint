# Security policy

## Reporting a vulnerability

Report it privately through GitHub: the repository's **Security** tab, **Report a vulnerability**.
Please do not open a public issue. Expect a first reply within 7 days.

## Supported versions

Only the latest release gets fixes. Consumers pin a full commit SHA, so a fix reaches them when they
move the pin; the changelog says which releases are affected.

## Fix deadlines

Counted from the day a vulnerability is confirmed: critical 7 days, high 30 days, medium 90 days, low
with the next related change.
